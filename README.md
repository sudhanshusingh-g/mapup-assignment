

# MapUp Geofencing & Real-time Alert System

A full-stack geofencing and real-time vehicle alert application.

## Technology Stack

- Backend: Go and Gin
- Frontend: React and Vite
- Database: PostgreSQL and PostGIS
- Real-time communication: WebSocket
- Maps: Leaflet
- Infrastructure: Docker and Docker Compose

## Project Structure

- backend: Go API and database logic
- frontend: React application
- backend/migrations: Database migrations

## Current Status

Initial project setup and database connectivity.
